# Swap scan

**Question:** can each role of a mind be replaced by a new implementation from its own folder,
through configuration alone, and carried by every screen, link, save, match, evaluation, fork and
inspector?

**Answer:** no, for 18 of the 19 roles tried; only a mind that writes its own muscles swaps cleanly.
The [AI testbed](../plans/2026-10-22-ai-testbed.md) plan is the work this decides; this record is
its evidence, and goes when that plan lands.

**How it was read:** four throwaway entrants at `91c006ae`, one for each group below, each a
deliberately trivial second implementation of each role: a joint-PD motor, a gait that stands
still, a support that does nothing, a recovery that curls up, a push, a guard that drops its hands,
a behaviour that backs away, a planner that rushes and punches, a navigator that walks straight, a
Commander that holds, an evaluation that stands for 5 s, a ring-out end rule. Each was plugged in
by configuration, run for a few seconds in Node (Rapier, 120 Hz), forked and replayed; the
browser flows were read, not run. Where a shared edit was needed, the smallest one was made and
recorded, so one blocker did not hide the next. Line numbers are `91c006ae`'s.

## Findings

Six causes account for nearly every row:

1. **Only minds register from outside the shared code.** Every role below a mind, and
   Commanders, evaluations and world kinds, is a closed list in a toolkit module.
2. **Registering does not make a part run.** A host builds the stock part itself: the fighter
   builder, the arbiter, the behaviour switch, the planner switch, recovery, the ground fight,
   the reptile.
3. **Interfaces are one implementation's shape**: the navigator's state, the motor's IK and
   stance, attack-shaped actions, two named hands, a humanoid view on every body.
4. **Mistakes are silent**: a motor's settings dropped, a faulted Arena link playing the preset,
   the refusal reason dropped, unknown keys crashing, unknown resources throwing mid-bout.
5. **Fit is mixed with entry, and registering enrols**: an unused weapon refused, a mind with no
   attacks entered, every registered mind in every pool and the fingerprint.
6. **Tools check kinds by name, and second lists are kept by hand**: `isFighter` gates, the
   `--ablate` slots, the Crypt's options, `unshown`, the boundary test's module list.

Held in every swap: fork and replay to the bit; the bout shared by browser and Node.

Kinds: blocker (a shared edit was needed), silent (the choice was ignored), friction (a workaround),
flow (a screen, link, save, match, evaluation, replay or inspector), doc (a document is wrong).

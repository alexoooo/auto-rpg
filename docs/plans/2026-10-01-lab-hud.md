# The lab's HUD: what remains

The lab's HUD is sections (`src/lab/hud/sections.ts`) filled with controls built from data
(`src/lab/hud/controls.ts`): the shell's, one module a section (`src/lab/hud/*-section.ts`), and
the scenario's panels (`LabScenario.panels`). Three chunks remain; each lands green and is
committed.

| | left | middle | right |
|---|---|---|---|
| **top** | Scenario | View | Character: Body, Items, Mind |
| **bottom** | Readout | Controls | Thinking (the mind's log) |
| | the transport, full width | | |

## 3. Actor and Balance

One place makes and drives a lab body -- `src/lab/actor.ts`:

```ts
export interface ActorOptions {
  readonly assist?: AssistCeiling;                 // BodyOptions.assist
  readonly stance?: StanceTuning;                  // BodyOptions.stance
}
export interface Actor { readonly body: Body; readonly world: World; drive(script: Tactics, options?: SkillOptions): Skills }
export function labActor(built: BuiltBody, world: World, options?: ActorOptions): Actor
```

- The modes take an actor instead of making a body: `startStance(actor)`, `startRun(actor, track)`,
  `startRoutine(actor)`, `throwBlow(actor, strike, distance)`. Their callers in `tests/`,
  `research/` and `scripts/` pass `labActor(built, world)` (`core-routine-battery.mjs` passes its
  tuning as `stance`). `ScenarioContext` gains `actor`, made by the shell's `load`.
- `src/lab/scenarios.ts`: `balance: number | null` in the address (null is the character's own, as
  `DuelRecipe.balance` falls back in `src/arena/duel.ts`).
- `controls.ts` gains `quantity(label, { min, step }, value, set)`; `character-section.ts`'s Body
  gains `quantity("Balance", ...)`; `LabPage` gains the loaded body's `spec`; `load` gives the
  actor `balanceCeiling(points, balancePoint(rulebook("arena")))`.
- Tests: `tests/lab-actor.test.mjs` (at 5 points the Stance holds a shove that fells it at 0),
  `tests/lab-scenarios.test.mjs` (the address with `balance`). `node scripts/fingerprint.mjs`
  reads the same before and after.

## 4. Mind

`src/lab/minds.ts`:

```ts
export interface LabMind { readonly id: string; tactics(script: Tactics): Tactics }
export const LAB_MINDS: readonly LabMind[] = [
  { id: "script", tactics: (script) => script },
  { id: "guard", tactics: () => ({ name: "guard", decide: () => standIntent() }) },
];
```

- `ActorOptions` gains `allows?: (recipe: Recipe) => boolean` (filters the repertoire the skills
  get) and `mind?: (script: Tactics) => Tactics` (what drives, given the scenario's script). With
  neither, the script and `REPERTOIRE` pass through untouched.
- The address gains `mind: string` (an id of `LAB_MINDS`) and `barred: readonly string[]` (`held`
  names found in `REPERTOIRE`). Changing either is a `load`.
- `character-section.ts` gains the Mind group: a chooser over `LAB_MINDS`' ids, and its actions,
  derived: for each hand, `recipeFor(REPERTOIRE, spec, hand)`, one switch per distinct
  `recipe.held`, shown by `strike.name`. The group's switches follow the loaded body's spec.
- Tests: `tests/lab-actor.test.mjs` (no options: same script object and `REPERTOIRE`; `allows`
  leaves a barred hand's `recipeFor` null; under `guard` the Routine throws nothing and stays
  put), `tests/lab-scenarios.test.mjs` (the address with `mind` and `barred`). The fingerprint
  reads the same.

## 5. Thinking

`src/lab/mind-log.ts` (no DOM, `import type` from core):

```ts
export interface MindLog { note(time: number, text: string): void; readonly revision: number;
  upTo(time: number, count: number): readonly { readonly time: number; readonly text: string }[] }
export function createMindLog(capacity?: number): MindLog
export function logged<T extends Tactics>(tactics: T, log: MindLog): T
```

- `logged` delegates (`Object.create(tactics, { decide })`), and notes a line when it differs from
  the last of its kind, at `sight.view.time`: `move 0.30 0.00` / `stand`; `right attack` /
  `right guard` (`HandAction.kind`); `strike chamber <Strike.name>` (`StrikeReport.phase`, nothing
  for null); `fallen`. No turn line: per step the asked turn is noise or silence, and it depends on
  the rate.
- The page composes it at the actor: `mind: (script) => logged(chosen.tactics(script), log)`.
- `"thinking"` joins `SECTIONS` and the template's right column; `src/lab/hud/thinking-section.ts`
  shows the log up to the shown time.
- The Blow's moment takes its time from `body.view.time` like the other three, so the shown time
  cuts the log exactly. The Run's and the Routine's Doing rows leave the Readout (and
  `Routine.doing` if nothing else reads it): the log says it for whichever mind drives.
- Tests: `tests/lab-mind-log.test.mjs` (rolls, cuts at a time on both sides, exact entries for
  scripted tactics, for 20 s of the Run's circle and for the Blow's phases in order). The
  fingerprint reads the same.
- `README.md` "The Lab" and `docs/architecture.md`'s lab bullet say what the page then has. This
  plan is deleted.

## Each chunk

`npm test`, `npm run check`, `npm run build`, the line-ending gate; each new test mutated red
once; a reviewer told to refute the diff; then the commit. In a browser, on a preview server on
another port: Balance 5 holds the Stance through a shove that fells it at 0; `guard` stands every
scenario still; barring the club's blow leaves the Routine walking and not striking; the address
keeps all three across a reload; the log writes a walk while W is held and the Blow's phases, and
shortens when scrubbed back.

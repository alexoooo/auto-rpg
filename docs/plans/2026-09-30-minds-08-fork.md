# Minds 08: state is data, and a fork is a load

## Goal

Everything of a bout that changes from step to step is plain data that saves and loads whole:
`Duel.save()` gives it, `Duel.load(saved)` puts a bout there in place, and the bout goes on from
a load exactly as it went on from the save. A load works on the bout the save came from (a
rewind) and on any bout built from the same recipe, in another world or on another thread (a
fork). Rollouts ([plan 06](2026-09-30-minds-06-oracle.md)) then fork by a load, at the cost of
the horizon alone.

It needs [plan 07](2026-09-30-minds-07-engine-save.md) (the physics) and comes after plans 02 to
05, whose modules it converts with the rest.

## What was measured

Node 24.19, core world, Rapier, 120 Hz, the fighter-rogue bout, with plan 07's engine: the
physics alone is not the state.

|---|---|

So the controllers' memory has to travel with the bytes. It lives today in closures: `let`s and
scratch objects of `stanceControl`, `motorControl`, `locomotion`, `strikeSkill`, the tactics, the
blow watch, the pool and the bout.

## The rules of state

1. **A module's memory is one object, `state`**, made where the module is made and exposed on
   what it returns. What a step writes and a later step reads before writing again is in it.
   What every step computes afresh before it reads it (the dynamics, the contact masses, the
   servo's work, a scratch vector) is not. In doubt, it is state: a field too many costs a few
   bytes; a field too few is a fork that drifts.
2. **State is plain data**: numbers, strings, booleans, null, plain objects, arrays, typed
   arrays, a `Map` or `Set` keyed by strings or numbers, `Vector3`, `Quaternion`. Not a function,
   a node, a body, a segment, a joint, or an object with a getter: `saveState` throws with the
   path of the first it meets.
3. **A constant is frozen, and a load never writes into a frozen object.** State may point at a
   table's entry (a posture, a recipe's footing); the save copies it, and a load puts a copy in
   the slot. A constant that is not frozen would be overwritten by a load, so the tables state
   can point at are frozen deep (`deepFreeze`), where a write throws.
4. **Sharing is kept.** Two slots that held one object at the save hold one object after the
   load (`reading.own` and `step.swing`; the command the skills write and the body holds).
5. **A load is in place.** An object at the same place in the live state, of the same kind and
   not frozen, is filled, not replaced: whoever holds the stance's reading or a `Vector3` of it
   holds it still. A slot that held null or another kind gets a new object, so nothing outside
   the state may keep, across a step, an object out of a slot that can be null.
6. **The bout's state is one root** (`Duel.state`), the modules' states hung on it, so rules 4
   and 5 hold across modules.

## `src/core/state.ts`

```ts
import { Quaternion, Vector3 } from "@babylonjs/core/Maths/math.vector.js";

/** A saved state: plain data sharing nothing with what it was saved from, good for `loadState` and for another thread. */
export type Saved = unknown;

/** The key that marks a saved vector or turn, which a thread boundary would strip of its class. */
const TAG = "~";
type Typed = Float64Array | Float32Array | Int32Array | Uint8Array;
const isTyped = (value: unknown): value is Typed => ArrayBuffer.isView(value) && !(value instanceof DataView);
const isPlain = (value: object): boolean => { const p: unknown = Object.getPrototypeOf(value); return p === Object.prototype || p === null; };
const isKey = (key: unknown): boolean => typeof key === "string" || typeof key === "number";

/**
 * A copy of the state under `root`: what `loadState` puts back. It throws, naming the path, at
 * anything that is not state: a function, a getter, a node or any object of a class other than
 * the ones a state may hold.
 */
export function saveState(root: object): Saved {
  const made = new Map<object, unknown>();
  const copy = (value: unknown, path: string): unknown => {
    if (typeof value === "function" || typeof value === "symbol") throw new Error(`${path} is a ${typeof value}, which is not state`);
    if (value === null || typeof value !== "object") return value;
    if (made.has(value)) return made.get(value);
    const keep = <T>(out: T): T => { made.set(value, out); return out; };
    if (value instanceof Vector3) return keep({ [TAG]: "vector", at: [value.x, value.y, value.z] });
    if (value instanceof Quaternion) return keep({ [TAG]: "turn", at: [value.x, value.y, value.z, value.w] });
    if (isTyped(value)) return keep(value.slice());
    if (Array.isArray(value)) {
      const list = keep([] as unknown[]);
      value.forEach((item, i) => list.push(copy(item, `${path}[${i}]`)));
      return list;
    }
    if (value instanceof Map) {
      const map = keep(new Map<unknown, unknown>());
      for (const [key, item] of value) {
        if (!isKey(key)) throw new Error(`${path} is keyed by an object, which is not state`);
        map.set(key, copy(item, `${path}.get(${String(key)})`));
      }
      return map;
    }
    if (value instanceof Set) {
      for (const item of value) if (!isKey(item)) throw new Error(`${path} holds an object, which is not state`);
      return keep(new Set(value));
    }
    if (!isPlain(value)) throw new Error(`${path} is a ${value.constructor?.name ?? "classed object"}, which is not state`);
    const record = keep({} as Record<string, unknown>);
    for (const [key, d] of Object.entries(Object.getOwnPropertyDescriptors(value))) {
      if (d.get || d.set) throw new Error(`${path}.${key} is computed, which is not state`);
      record[key] = copy(d.value, `${path}.${key}`);
    }
    return record;
  };
  return copy(root, "state");
}

/**
 * Put `saved` (a `saveState`) into the state under `live`, in place: an object of `live`'s that
 * is of the saved one's kind, not frozen and not already filled is filled, and any other slot is
 * given a new one; two slots that shared an object at the save share one after.
 */
export function loadState(live: object, saved: Saved): void {
  const made = new Map<object, unknown>(), filled = new Set<object>();
  const usable = (was: unknown): was is object => typeof was === "object" && was !== null && !filled.has(was) && !Object.isFrozen(was);
  const fill = (was: unknown, value: unknown): unknown => {
    if (value === null || typeof value !== "object") return value;
    if (made.has(value)) return made.get(value);
    const keep = <T extends object>(out: T): T => { made.set(value, out); filled.add(out); return out; };
    const tag = isPlain(value) ? (value as Record<string, unknown>)[TAG] : undefined;
    if (tag === "vector") {
      const [x, y, z] = (value as { at: [number, number, number] }).at;
      return keep(usable(was) && was instanceof Vector3 ? was.set(x, y, z) : new Vector3(x, y, z));
    }
    if (tag === "turn") {
      const [x, y, z, w] = (value as { at: [number, number, number, number] }).at;
      return keep(usable(was) && was instanceof Quaternion ? was.set(x, y, z, w) : new Quaternion(x, y, z, w));
    }
    if (isTyped(value)) {
      if (usable(was) && isTyped(was) && was.constructor === value.constructor && was.length === value.length) { was.set(value); return keep(was); }
      return keep(value.slice());
    }
    if (Array.isArray(value)) {
      const list = keep(usable(was) && Array.isArray(was) ? was as unknown[] : []), old = list.slice();
      list.length = value.length;
      value.forEach((item, i) => { list[i] = fill(old[i], item); });
      return list;
    }
    if (value instanceof Map) {
      const map = keep(usable(was) && was instanceof Map ? was as Map<unknown, unknown> : new Map<unknown, unknown>()), old = new Map(map);
      map.clear();
      for (const [key, item] of value) map.set(key, fill(old.get(key), item));
      return map;
    }
    if (value instanceof Set) {
      const set = keep(usable(was) && was instanceof Set ? was as Set<unknown> : new Set<unknown>());
      set.clear();
      for (const item of value) set.add(item);
      return set;
    }
    const record = keep(usable(was) && isPlain(was) ? was as Record<string, unknown> : {});
    for (const key of Object.keys(record)) if (!(key in (value as object))) delete record[key];
    for (const [key, item] of Object.entries(value as object)) record[key] = fill(record[key], item);
    return record;
  };
  if (fill(live, saved) !== live) throw new Error("a state loads into a state of its own kind");
}

/** `value` frozen, and everything it holds: a constant a state may point at (`loadState` never writes into one). */
export function deepFreeze<T>(value: T): T {
  if (typeof value === "object" && value !== null && !Object.isFrozen(value)) {
    Object.freeze(value);
    for (const item of Object.values(value)) deepFreeze(item);
  }
  return value;
}
```

A `Saved` crosses a thread boundary as it is (`postMessage` keeps maps, sets, typed arrays and
sharing), which is why a vector is saved as a tagged triple and not as a `Vector3`.

## `src/arena/duel.ts`

```ts
/** A bout at a step, whole: whose bout it is, the physics' bytes and every module's memory. Plain data. */
export interface DuelSave {
  readonly recipe: DuelRecipe;
  readonly physics: Uint8Array;
  readonly state: Saved;
}
```

```ts
  /** The bout as the last step left it: what `load` puts back, here or in any bout of this recipe. */
  save(): DuelSave { return { recipe: this.recipe, physics: this.world.physics.save(), state: saveState(this.state) }; }

  /**
   * Put the bout where `saved` left one of this recipe: the next step is the step that followed
   * the save. The page's hooks hear nothing of it.
   */
  load(saved: DuelSave): void {
    // Two bouts of different bodies can have worlds of the same counts, which the physics would take.
    if (JSON.stringify(saved.recipe) !== JSON.stringify(this.recipe)) throw new Error("that save is of another bout's recipe");
    this.world.physics.load(saved.physics);
    loadState(this.state, saved.state);
  }
```

`this.state` is built at the end of the constructor from the table's last row. `verdict` and the
fields beside it become getters over it (`get verdict() { return this.state.verdict; }`), so
`Duel`'s readers do not change.

## Rollouts by load

`rollout` takes `save` (a `DuelSave` taken at step `from`) and a bout to load it into:

```js
/** A bout for each recipe this thread has been asked for, built once and loaded into for every fork of it. */
const bouts = new Map();
async function boutOf(recipe) {
  const key = JSON.stringify(recipe);
  if (!bouts.has(key)) bouts.set(key, await buildBout(recipe));
  return bouts.get(key);
}
```

With `save`, `rollout` takes `boutOf(recipe)`, calls `duel.load(save)` and `duel.play(branch)`
(which replaces whatever tape the save had queued, as a replay drops the tape from the fork on),
and goes on as it does after a replay: the same `at`, nudges, trace and row. Without `save` it replays as before, in a bout of its own. The
oracle's decision becomes `{ recipe, save: trunk.duel.save(), from, branch, steps, nudges }`, and
`--replay` keeps the old way for the comparison. `--seconds` then starts at the arena's cap.

By arithmetic, to be read by the script: a fork by load costs the horizon alone, 240 steps and
about 0.3 s, whatever the bout's length, where a replay at step 7200 costs 9.7 s. A save is the
physics' bytes (about 330 kB for two armed humans) and the state, copied to each worker.

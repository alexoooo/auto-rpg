# Blows 02: a contact names its shapes, and a blow has two sides

## Goal

The engine says which shapes touched; a rigid body says whose each shape is; and a blow's record
is two sides, each with the share of the energy it took, its damage and its wound. The rule that
fills it is today's, written as shares: the struck side takes all, the striking side none, two
hands meeting take none. No fight wounds differently: the fingerprint is equal before and after.

This is the record and the reading plan 03's rule needs, landed without the rule.

## The engine (`engine.ts`, `rapier.ts`)

```ts
/** One pair of shapes that touched: this body's and the other's. */
export interface ContactPair {
  /** Which of this body's shapes, and which of the other's, in the order `addBody` was given them. */
  readonly mine: number;
  readonly theirs: number;
  /** Where they touch, world, m: the pair's solver contact points averaged. */
  readonly point: Vec3;
  /** The pair's normal, world, unit, from this body into the other. */
  readonly normal: Vec3;
  /** The impulse the solver pushed the pair apart with in the last step, N s. */
  readonly impulse: number;
}
```

`Contact` gains:

```ts
  /** Each pair of shapes that touched, in this body's shapes' order, then the other's. */
  readonly pairs: readonly ContactPair[];
```

Its `point`, `normal` and `impulse` stay what they are: the pairs summed, weighted by impulse.

Rapier: `addBody` records each collider's place among the body's shapes by its handle; in
`contactsOf` the inner callback has `mine`'s index `k` and looks up `theirs`'s. Several manifolds
of one pair of colliders are one `ContactPair`, their impulses summed and their points weighted
by impulse. The pairs survive a save and a load as the contacts do (`a loaded world keeps the
last step's contacts`).

## Whose a shape is (`rigid.ts`)

```ts
/** Whose a rigid body's shape is: its segment's own, or an item it holds. */
export type ShapeOwner =
  | { readonly kind: "segment" }
  | { readonly kind: "held"; readonly held: HeldSpec };
```

`Rigid` gains:

```ts
  /** Whose each of `shapes` is, in their order. */
  readonly owners: readonly ShapeOwner[];
```

`rigidOf` writes it beside `shapes`: `[{ kind: "segment" }]`, then one `held` for each shape of
each held item.

## The record (`blows.ts`)

```ts
/** One side of a blow: the surface that met the other's. */
export interface BlowSide {
  readonly fighter: string;
  readonly segment: string;
  /** The held item whose shape was touched, by name; null for the segment's own. */
  readonly item: string | null;
  /** The mass the contact meets on this side, kg. */
  readonly kg: number;
  /** The share of the blow's energy this side took, 0 to 1. */
  readonly share: number;
  /** Hit points, in the rulebook's unit: its share's worth. */
  readonly damage: number;
  /** What it did to this side's pool; null where it took no share. */
  readonly wound: Wound | null;
}

/** A blow: two surfaces of two sides' bodies that met. */
export interface LandedBlow {
  /** The world's clock when it landed, s. */
  readonly time: number;
  /** Where, world, m, and the normal, the first side into the second. */
  readonly point: Vec3;
  readonly normal: Vec3;
  /** The closing speed along the normal, m/s. */
  readonly closing: number;
  /** J. */
  readonly energy: number;
  readonly sides: readonly [BlowSide, BlowSide];
}

/** Whether `blow` wounded nobody: neither side took a share. */
export const isClash = (blow: LandedBlow): boolean => blow.sides.every((side) => side.share === 0);

/** The sides `blow` wounded. */
export const woundedIn = (blow: LandedBlow): readonly BlowSide[] => blow.sides.filter((side) => side.wound !== null);
```

`watchBlows` keeps its loop, `STRIKERS` and its touch memory. Where it made a blow it now:

- takes the pair of `contact.pairs` with the greatest impulse (the first of equals), and reads
  each side's surface: `rigid.owners[pair.mine]` of the striker's segment, `owners[pair.theirs]`
  of the struck one's;
- writes `shares`: `[0, 0]` where the struck segment is a striker too, else `[0, 1]`;
- wounds each side whose share is over 0 with `blowDamage(rules, "blunt", share * energy)`;
- writes `sides` as the striker's, then the struck's. `point`, `normal` and `closing` are the
  merged contact's, as they are today.

The module's comment says a blow has two sides and what fills them; "A hand meeting a hand is a
clash" stays true and is said as shares.

## Tests

1. `core-engine`, **`a body of two shapes names the one that touched`**: a body of two balls
   0.4 m apart, another resting on the second: its contact's `pairs` is one pair, `mine` 1 and
   `theirs` 0; from the other body, `mine` 0 and `theirs` 1, the normal turned over, the impulse
   the same; the merged `point`, `normal` and `impulse` equal the pair's. A long box laid across
   both balls: two pairs, in order, and the merged point is theirs weighted by impulse.
2. `core-held`, **`a rigid body says whose each shape is`**: a hand alone is
   `[segment]`; a hand with the club is `[segment, held, held]`, each `held` the club's
   `HeldSpec`, parallel to `shapes`.
3. `core-blows`, every test's blow asserted whole in the new shape. Added:
   **`a_blow_names_the_item_that_touched_and_the_hand_when_it_was_the_hand`**: a `lone` hand
   holding a ball 0.3 m out, sent so the ball lands: `sides[0].item` is the item's name; sent so
   the hand's own ball lands: null.
4. `arena-fork`: the fork's blows equal the bout's, records whole.
